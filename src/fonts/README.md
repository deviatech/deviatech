Fonts from the official Google Fonts repository: https://github.com/google/fonts/tree/main/ofl . Family directories: dmsans, inter, vazirmatn, notosansarabic, spacegrotesk, ibmplexmono, fraunces. Original OFL licenses retained. TTF files losslessly encoded as WOFF2 using fontTools; original family names and variable axes retained. Self-hosting removes build-time font download dependencies.
